# Wi-Fi Relay 1.0.0-30

**[Download bundle.deb — recommended](https://github.com/3togo/gnome-wifi-hotspot/releases/download/v1.0.0-30/bundle.deb)**

The bundle includes settings, the daemon, GNOME controls and tray controls.
Install with `sudo apt install ./bundle.deb`. APT supplies system dependencies;
GNOME Shell is optional. Ubuntu 26.10 is the validated distribution release.
The stable default remains create_ap; NetworkManager AP+STA remains experimental.

Separate packages remain available for users who want only selected components.
Install either the bundle or matching separate packages, not both layouts.

## Upgrade and rollback

Stop sharing before installation. Keep an owner-only backup of
`/etc/wifi-hotspot.conf` and the previous matching packages. Installing the bundle
replaces separate packages while preserving configuration and preferences.
Sharing does not resume automatically after an upgrade.

To roll back, stop sharing and install the saved previous bundle, or all saved
matching standalone and optional-control packages together, using
`sudo apt install --allow-downgrades ...`. APT switches layouts when necessary.
Avoid purge during rollback if system configuration should be retained.

## Validation scope

The runtime files match the tested candidate. Final changes promote version
metadata and release documentation. Checksums accompany the downloads; artifacts
are unsigned, and this release does not establish a signed APT repository.

- 344 Python tests (one bench-dependent skip), tray checks, GTK widgets, service
  integration, sanitized applet and GNOME Shell checks passed.
- Disposable-container lifecycle checks covered legacy and split upgrades,
  bundle replacement and upgrade, switching back, removal, purge and fresh
  installation, including credential preservation.
- USB-controlled physical testing completed four DHCP/DNS/HTTPS and cleanup
  cycles on one Android 15 phone and Intel CNVi/iwlwifi adapter. Invalid TLS was
  rejected. An earlier connection timeout and independently reproduced upstream
  negative-DNS variation remain recorded.
- Six distinct LightDM PAM/logind sessions in a software-rendered container
  checked enabled, disabled and re-enabled startup on GNOME 51 and XFCE 4.20.
  Host GDM, physical-seat and hardware graphics behavior were not exercised.

See the [candidate validation record](1.0.0-30-rc1.md),
[USB evidence](../evidence/physical-usb-1.0.0-30-rc1.json) and
[desktop-login evidence](../evidence/desktop-login-container-1.0.0-30-rc1.json).
Other clients/drivers, multi-adapter routing, suspend/reboot fault trials,
extended soaks and RPM packaging remain outside this release's validated scope.
