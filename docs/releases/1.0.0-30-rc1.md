# Wi-Fi Relay 1.0.0-30~rc1 candidate

This candidate adds the all-in-one package and the CMake build entry point.
It is not a published stable release. The network implementation is unchanged.

## Build and install

Run `./build.sh`, then verify `SHA256SUMS` from inside `build/dist/`.
Install only the bundle with
`sudo apt install ./build/dist/gnome-wifi-hotspot-bundle_1.0.0-30~rc1_all.deb`.
Do not pass all four packages to APT together: the bundle replaces the separate
packages. Stop sharing before installation. Keep a private backup of
`/etc/wifi-hotspot.conf` and the previous packages for rollback.

## Release gates

- Run unit, service integration, real-widget and extracted-package smoke checks.
- Run `sudo make test-package-lifecycle` in the repository if the current user
  cannot access Docker. It uses a disposable Ubuntu 26.10 container and does not
  install packages on the host. The checks cover split-to-bundle installation,
  bundle upgrade, switching back to separate packages, removal, purge and fresh
  installation. Configuration must survive upgrades and layout switches.
- Install the candidate on the test host and verify physical DHCP, DNS and HTTPS
  from another device, followed by stop/start and reconnect.
- Log in afresh on GNOME and a compatible tray desktop and check the appropriate
  controls, disabled-startup preference, and absence of duplicate controls.

The read-only installed smoke check does not establish client connectivity.
Fixture-based desktop checks do not establish fresh-login behavior on real
GNOME and XFCE/KDE sessions. Keep these gates pending until measured.

The lifecycle runner selects download sources using a direct public-IP country
lookup with bounded timeouts. China uses the 1ms Docker mirror and Tsinghua Ubuntu
mirror; other countries, or a failed lookup, use the distribution defaults.
Set `WIFI_RELAY_COUNTRY=CN` to override geolocation when the public exit IP does
not reflect the desired region. `WIFI_RELAY_TEST_IMAGE` and
`WIFI_RELAY_APT_MIRROR` override either source independently. For example:

```sh
WIFI_RELAY_COUNTRY=CN make test-package-lifecycle
```

APT signature checks remain enabled. Mirror choices apply only inside the
disposable test container and do not change host Docker or APT configuration.

## Validation status, 15 October 2026

Automated source and extracted-package checks passed, including 343 Python tests
(one skipped), tray checks, service integration, GTK widgets, GNOME Shell and
the sanitized applet harness. The disposable Ubuntu 26.10 lifecycle suite passed
using the China mirrors: legacy and split upgrades, split-to-bundle replacement,
bundle upgrade, switching back to separate packages, removal, purge and fresh
installation. Credentials survived upgrades and layout switches; fresh
installation generated secure defaults. These automated checks do not establish
real desktop login behavior or client traffic; subsequent USB traffic results
are recorded below. Fresh desktop logins remain pending.

An additional [live desktop and physical-test attempt](../evidence/physical-desktop-1.0.0-30-rc1.json)
verified disabled startup, repeated-launch single-instance behavior and indicator
registration in the existing XFCE/X11 session. Preferences and the tray service
state were restored. This was not a fresh login. The Android 15 wireless-ADB
traffic attempt was blocked by loss of device control during network switching;
it established no DHCP/DNS/HTTPS pass. Sharing was stopped, the AP interface was
removed, and the phone's original Wi-Fi and power setting were restored; the
temporary probe was removed. Fresh XFCE and GNOME logins remain untested.

A subsequent [USB-controlled physical run](../evidence/physical-usb-1.0.0-30-rc1.json)
completed four start/connect/traffic/stop cycles using one Android 15 phone and
the Intel CNVi/iwlwifi adapter with stock NetworkManager. Each completed cycle
verified fresh hotspot association and DHCP, Wi-Fi-bound DNS and HTTPS, and AP
cleanup. A separate phone probe rejected the invalid TLS hostname. An earlier
negative-endpoint connection timeout and a negative-DNS comparison mismatch are
retained in the evidence. Repeated host-only queries independently reproduced
NXDOMAIN/NOERROR variation for the same names outside Relay's forwarding path.
The phone's Wi-Fi and power settings were restored and its probe was removed.
This limited client-traffic gate is complete; it does not establish the full
ten-cycle matrix, other client/driver coverage, suspend, reboot or a long soak.

## Rollback

Stop sharing, then install the saved matching standalone, GNOME and tray packages
in one transaction using `apt install --allow-downgrades`. APT removes the bundle.
Do not purge packages during rollback if configuration should be preserved.

Candidate validation logs and source/package hashes are generated by
`python3 tools/validate.py --full --with-lifecycle`. A report lists unperformed
checks explicitly; a passing subset alone does not authorize stable publication.
