# Wi-Fi Relay 1.0.0-29 release maintenance

Revision 29 makes settings follow native desktop styling and fit their content.
See [release notes](../../RELEASE_NOTES.md) for changes and validation limits.
Supported release platform: Ubuntu 26.10 (Stonking). The stable default remains
create_ap; NetworkManager remains experimental.

## Upgrade and rollback

Stop sharing first. Back up `/etc/wifi-hotspot.conf` with owner-only permissions
and keep the previous matching standalone and optional GNOME/tray packages.
Install all selected packages at the same version in one APT transaction.
Configuration and user preferences are preserved; upgrades do not resume sharing.

To roll back, stop sharing and install the saved matching packages together with
`apt install --allow-downgrades`. Restore the private configuration only if
necessary. Confirm status, client addressing, and forwarding before use.
Removing an optional desktop integration leaves the standalone service intact.

## Evidence

Published validation records identify exact source and package hashes. Native
GTK tests cover theme changes, dialogs, all four settings pages, enlarged text,
and constrained screens. GNOME/KDE desktop preferences are simulated in these
checks; separate desktop sessions were not validated.

The unchanged daemon and backend retain the
[revision-28 physical baseline](../evidence/hardware-release-1.0.0-28.json).
Revision-29 physical traffic was not rerun. Artifacts are unsigned. AppArmor and
permanent firewall policy remain enforced as configured on the host.
